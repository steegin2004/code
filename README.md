# Engineering Calculator Hub

A responsive web app with four calculators for mechanical engineering students, built with HTML, CSS and JavaScript.

**Live demo:** https://engcalc.ccbp.tech/

## Features

- **Unit Converter:** converts length (m, cm, mm, inch, foot), mass (kg, g, lb) and temperature (°C, °F, K)
- **Torque Calculator:** T = F × r
- **Stress Calculator:** σ = F / A, with the result in MPa
- **Gear Ratio Calculator:** ratio = driven teeth / driver teeth, with optional driven gear speed in RPM
- Input validation with clear error messages for empty, negative or zero values
- Responsive layout that works on mobile, tablet and desktop

## Technologies Used

- HTML5 (semantic elements)
- CSS3 (CSS Grid, Flexbox-free responsive layout, media queries)
- JavaScript (functions, DOM manipulation, event handling)

## Project Structure

```
index.html   - page structure and calculator forms
style.css    - styling and responsive layout
script.js    - calculator logic and input validation
```

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
